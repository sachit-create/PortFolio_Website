# Sachit Kohli | Portfolio

A personal portfolio website showcasing projects, skills, and professional background.

## Overview

This repository contains a lightweight, responsive portfolio built with HTML and CSS. It highlights:

- projects and work samples
- resume download
- GitHub and LinkedIn links
- a modern single-page design

## Live Preview

Open `index.html` in a browser to view the portfolio locally.

## Project Structure

- `index.html` — main portfolio page
- `favicon.svg` — site favicon
- `resume.pdf` — downloadable resume
- `internalhackthonteam2.jpeg` — project image asset

## Run Locally

You can view it directly or serve it locally:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
